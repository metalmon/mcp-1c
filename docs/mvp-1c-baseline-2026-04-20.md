Перед отключением MCP желательно еще снять:

- структуру `Catalog.ДоговорыКонтрагентов` (поля для автоподбора договора),
- структуру `Catalog.Номенклатура` (минимальные поля для строк товаров),
- по 1-2 примера заполненных элементов (если появятся данные),

и сохранить в этот же файл отдельным блоком `supplement`.
